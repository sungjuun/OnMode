# 로드맵

1. **MVP:** 웹 5개 메뉴, 로컬 체험, 타이머와 보상, 학습·독서, 공부방, 계정과 스터디. 데스크톱·모바일 브라우저와 로컬 Supabase에서 검증.
2. **웹 베타:** 이메일 비밀번호 재설정과 계정 삭제 구현 및 로컬 검증 완료. 남은 작업은 승인된 Supabase 프로젝트와 Vercel 연결, 운영 이메일 확인·발송 검증, 운영 로그와 백업 정책, 실제 사용자 대상 접근성 및 사용성 점검, 필요에 따른 기록 페이지 조회와 그룹 검색 개선.
3. **모바일 베타:** Capacitor Android/iOS 프로젝트 생성, 기기별 저장소·백그라운드 복귀 확인, 로컬 알림, 인증 딥 링크, 서명 및 심사 준비.
4. **후속 기능:** 밝게·어둡게·시스템 테마, 기간별 스터디 챌린지, 그룹 공지·기본 채팅, 공부방 배치·겹침 순서 편집, ISBN·제목·저자 도서 검색, 판본 선택, 카메라·사진 바코드 인식과 스터디 공동 도서관 구현 완료. 공동 도서관은 공용 공간 배치·도서 목록·개인 서재 가져오기·집중 연결을 제공한다. 다음 후보는 방 회전·크기 편집과 고급 채팅이다. 바코드의 실기기·네이티브 검증, 공동 도서관의 아이템 확장·공유 독서 목표·그룹 업적과 시즌 시스템도 후속 범위다. 도서 조회를 상용·대규모로 제공하기 전에는 공급자의 최신 이용 정책과 처리량에 맞는 연동 방식을 결정한다. 결제와 프리미엄은 운영 기반을 갖춘 뒤 도입.
