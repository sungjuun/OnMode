# 로드맵

1. **MVP:** 웹 5개 메뉴, 로컬 체험, 타이머와 보상, 학습·독서, 공부방, 계정과 스터디. 데스크톱·모바일 브라우저와 로컬 Supabase에서 검증.
2. **웹 베타:** 이메일 비밀번호 재설정 구현과 로컬 검증 완료. 남은 작업은 승인된 Supabase 프로젝트와 Vercel 연결, 운영 이메일 확인·발송 검증, 계정 삭제 절차, 운영 로그와 백업, 실제 사용자 대상 접근성 및 사용성 점검, 필요에 따른 기록 페이지 조회와 그룹 검색 개선.
3. **모바일 베타:** Capacitor Android/iOS 프로젝트 생성, 기기별 저장소·백그라운드 복귀 확인, 로컬 알림, 인증 딥 링크, 서명 및 심사 준비.
4. **성장 기능:** 아이템 배치 편집, 그룹 챌린지·공지·채팅, 공동 도서관, ISBN 검색, 다크 모드. 결제와 프리미엄은 운영 기반을 갖춘 뒤 도입.
