# 로드맵

1. **MVP:** 웹 5개 메뉴, 로컬 체험, 타이머와 보상, 학습·독서, 공부방, 계정과 스터디. 자격증·시험일 없는 개인공부 등록과 기존 자격증별 과목 관리를 함께 지원한다. 데스크톱·모바일 브라우저와 로컬 Supabase에서 검증.
2. **웹 베타:** 이메일 비밀번호 재설정, 계정 삭제, 공개 그룹 검색과 결과 더 보기, 집중 기록 필터·정렬·페이지 이동 구현 및 로컬 검증 완료. 남은 작업은 승인된 Supabase 프로젝트와 Vercel 연결, 운영 이메일 확인·발송 검증, 첨부 파일 정리 서버 작업, 운영 로그와 백업 정책, 실제 사용자 대상 접근성 및 사용성 점검.
3. **모바일 베타:** Capacitor Android/iOS 프로젝트 생성, 기기별 저장소·백그라운드 복귀 확인, 로컬 알림, 인증 딥 링크, 서명 및 심사 준비.
4. **후속 기능:** 밝게·어둡게·시스템 테마, 기간별 스터디 챌린지·서버 집중 기반 그룹 업적 6종·월간 스터디 시즌, 그룹 공지·채팅 전송·수정·삭제·읽음 인원 표시와 멤버 전용 사진·파일 첨부, 공부방 배치·겹침 순서·가구 회전·크기 편집, ISBN·제목·저자 도서 검색, 판본 선택, 카메라·사진 바코드 인식과 스터디 공동 도서관 구현 완료. 공동 도서관은 공용 공간 배치·가구 회전과 크기·액자와 노트북 배치·도서 목록·개인 서재 가져오기·집중 연결·도서별 공유 독서 목표와 명시적 진도 공유·기간별 독서 도전을 제공한다. 바코드의 실기기·네이티브 검증은 후속 범위다. 도서 조회를 상용·대규모로 제공하기 전에는 공급자의 최신 이용 정책과 처리량에 맞는 연동 방식을 결정한다. 결제와 프리미엄은 운영 기반을 갖춘 뒤 도입.
