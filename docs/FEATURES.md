집중 기록은 1초 이상 저장합니다. 보상은 온전한 분 단위로 지급합니다. 사용자 지정 휴식이 0분이거나 설정 시간을 채우기 전에 종료하면 휴식은 시작하지 않습니다. 목표 연속 기록은 현재 설정한 목표를 기준으로 다시 계산합니다. 그룹 집계는 현재 브라우저의 시간대 기준입니다. 그룹 공동 목표는 월요일 시작 기준 주간 목표입니다.

MY의 집중 기록은 오늘·최근 7일·최근 30일·직접 선택한 기간과 활동·집중 방식을 함께 적용할 수 있습니다. 날짜는 기기 시간대의 집중 완료일을 기준으로 하며 시작일과 종료일을 모두 포함합니다. 조건에 맞는 횟수와 집중 시간 합계를 표시하고, 최근 또는 오래된 순으로 20개씩 보여 줍니다. 체험 모드와 계정 모드에서 같은 방식으로 조회합니다.

ISBN 조회는 사용자가 검색 버튼을 누를 때 Open Library의 도서 메타데이터를 읽습니다. ISBN 10·13자리의 확인 숫자를 검증하고 ISBN-13으로 통일해, 한 서재에서 같은 ISBN을 중복 등록하지 않도록 합니다. 확인 숫자 검증만으로 실제 발급·출판 여부를 보증하지는 않습니다. 검색 결과는 제목·저자·페이지 수와 출처를 보여주며, 사용자가 적용한 뒤 직접 수정하고 저장합니다. 없는 저자·페이지 수는 추정하지 않고 필수 입력으로 남깁니다. 조회 실패·결과 없음·오프라인에서도 직접 등록할 수 있고 ISBN은 선택 사항입니다. 기존 직접 등록 자료는 유지하며, 다른 계정의 서재는 공개하지 않습니다. 제목·저자 검색은 작품과 판본을 구분해 각각 10개씩 조회합니다. 판본의 ISBN·페이지 수만 양식에 적용하며 저자는 작품 정보 기준으로 확인·수정할 수 있습니다. 작품별 중간 페이지 수나 다른 판본의 ISBN은 사용하지 않습니다. 선택한 판본의 페이지 수가 없으면 필수 직접 입력으로 남깁니다.

방 꾸미기는 아이템 배치·치우기와 위치 편집을 지원합니다. 책상·의자·조명·액자·화분·책장·노트북은 마우스·터치·키보드·방향 버튼으로 이동할 수 있으며, 벽지는 공간 테마로 적용합니다. 편집은 저장 전에 미리보기로 표시하고, 취소와 기본 위치 복원을 지원합니다. 개인 방과 공동 도서관에서 앞으로 가져오기·뒤로 보내기와 Page Up·Page Down으로 선택한 가구를 보이는 가구 사이에서 한 단계씩 이동할 수 있습니다. 가구 중심을 기준으로 왼쪽·오른쪽 90도 회전(0·90·180·270도), 50~120% 크기 조절(10% 단위)을 제공합니다. 기본 모양은 기존 벽·바닥 이동 범위를 유지하며, 모양을 바꾼 가구는 회전·크기를 반영한 전체 윤곽이 방 안에 들어오도록 위치를 자동 보정합니다. 변경 후에도 드래그와 화살표는 화면 기준 방향으로 이동합니다. 선택 가구 모양 초기화는 회전·크기를 되돌리고, 기본 위치는 전체 위치·순서·모양을 복원합니다. 위치·순서·모양을 함께 저장하고, 취소·새로고침·숨기기 후 재배치에도 반영합니다. 브라우저 체험에서는 실제 그룹·온라인 인원·랭킹을 표시하지 않습니다.

챌린지는 그룹장이 생성하며 1~90일 동안 공동 집중 시간을 쌓습니다. 멤버는 별도 신청 없이 함께 참여하고, 시작 예정·진행 중·목표 달성·기간 종료·취소 상태를 확인합니다. 챌린지 생성과 시작 이후 시작한 집중이 종료일 안에 완료되어야 집계합니다. 취소 뒤에 종료한 집중은 제외합니다. 탈퇴한 멤버의 기존 기여는 공동 합계에 남지만, 계정 삭제 시 개인 기록과 함께 제거됩니다. 멤버별 표는 현재 가입 기간의 기여만 표시합니다. 챌린지에 별도 XP·코인 보상은 없으며 일반 집중 보상만 지급합니다.

공지는 그룹장이 작성·수정·삭제하며, 그룹 멤버만 읽을 수 있습니다. 제목 80자, 내용 5,000자 이내의 일반 텍스트를 지원합니다. 최신순으로 20개씩 더 불러올 수 있으며, 변경 내용은 기존 그룹 실시간 연결 또는 주기 조회로 갱신합니다. 수정·삭제는 읽었던 버전과 현재 버전이 같아야 합니다. 충돌 시 초안을 유지하고 최신 목록을 확인하도록 안내합니다. 새 그룹장이 기존 공유 공지를 이어서 관리합니다.

그룹 업적은 1분 이상 완료해 그룹에 반영된 서버 집중 기록만 집계합니다. 첫 집중, 누적 1시간·10시간, 집중 10회·100회, 서로 다른 3명의 집중 완료 등 6종을 제공합니다. 같은 사람의 여러 기록은 참여 인원에 중복 계산하지 않습니다. 달성 전에는 진행률을 표시하고, 달성 후에는 확인 날짜와 배지를 보관합니다. 달성은 집중 완료와 같은 DB 트랜잭션에서 기록하며 재시도·동시 완료도 그룹·업적당 한 번만 기록합니다. 설치 시 기존 클라우드 그룹 기록도 점검하며, 과거의 정확한 달성일을 추정하지 않고 확인 시각을 남깁니다. 멤버 탈퇴나 계정 삭제 후에도 달성 배지는 그룹에 남습니다. 계정 삭제로 현재 기여 합계가 줄어도 이미 달성한 배지는 회수하지 않으며 개인 식별자·집중 기록 ID는 배지에 저장하지 않습니다. 그룹 삭제 시에는 배지도 삭제합니다. 별도 코인·XP 보상은 없습니다. 현재 그룹 멤버만 조회할 수 있고 직접 달성을 등록하거나 수정할 수 없습니다.

스터디 시즌은 한국 시간 기준 매월 1일 자정에 바뀝니다. 현재 그룹 멤버는 이번 달을 포함한 최근 12개월의 집중 합계·완료 횟수·기여 인원과 공동 목표(1·10·30시간)를 확인할 수 있습니다. 그룹에 반영된 1분 이상 집중은 완료한 달에 한 번 집계하며 달을 걸쳐 진행한 집중도 완료한 달에 합산합니다. 순위는 기여 기록이 있는 현재 멤버 중 최대 20명을 보여 주고, 동점자는 공동 순위를 받습니다. 본인 순위와 기록은 상위 20명 밖에서도 확인할 수 있습니다. 탈퇴자의 이름은 순위에서 빠지고 기존 기여는 그룹 합계에 남습니다. 계정을 삭제하면 해당 계정의 기록이 제거되어 과거 시즌의 합계에도 반영됩니다. 별도 코인·XP는 지급하지 않습니다.

채팅은 현재 그룹 멤버만 조회·전송할 수 있으며, 가입 이전의 그룹 대화도 볼 수 있습니다. 일반 텍스트 2,000자 이내, 이전 대화 30개 단위 조회, 실시간 수신과 주기 조회, 실패 후 재전송을 지원합니다. 서버는 사용자별 분당 새 메시지 30개를 허용하며 같은 전송 요청 ID의 재시도는 새 메시지로 세지 않습니다. 본인 메시지는 연필 버튼으로 수정하고 Ctrl / ⌘ + Enter로 저장할 수 있습니다. 수정 내용은 멤버에게 실시간으로 반영하고 “수정됨”을 표시하며, 원래 작성 시각과 대화 순서는 유지합니다. 저장한 수정 요청의 동일 재시도는 수정 시각·버전·갱신 이벤트를 중복 반영하지 않습니다. 다른 기기에서 먼저 수정하거나 삭제하면 저장을 차단하고 초안을 유지합니다. 충돌 안내에서 필요한 내용을 복사하고 명시적으로 수정을 취소한 뒤 최신 메시지를 다시 열 수 있습니다. 그룹장도 다른 사람의 내용을 수정할 수는 없습니다. 본인과 그룹장만 메시지를 삭제할 수 있고, 내용은 지우되 삭제 표시는 남깁니다. 삭제된 메시지는 수정으로 복원하지 않으며, 탈퇴자는 자신의 이전 메시지도 수정할 수 없습니다. 계정 삭제 시에는 그 사용자의 메시지 행도 제거합니다.

메시지마다 10MB 이하 JPG·PNG·WebP·PDF·TXT 파일 한 개를 첨부할 수 있습니다. 설명은 선택이며, 사진 미리보기와 파일 다운로드는 사용자가 버튼을 눌렀을 때 시작합니다. 전송 전에는 업로더만 접근하고, 전송 후에는 현재 그룹 멤버만 접근합니다. 같은 전송을 재시도해도 파일이 중복되거나 덮어써지지 않습니다. 첨부는 전송 전에 취소할 수 있고 예약은 15분 뒤 만료됩니다. 보낸 메시지의 설명은 수정할 수 있으며 파일은 메시지와 함께 삭제합니다. 메시지·계정·그룹 삭제 즉시 파일 접근이 끊기고, 정리 작업이 저장소에서 실제 파일을 제거합니다.

내 메시지 아래의 “읽음 N명”은 현재 그룹 멤버 중 본인을 제외하고 해당 메시지의 현재 버전을 확인한 인원입니다. 채팅 안내에서 읽음 인원 공개를 알립니다. 화면이 보이고 창에 초점이 있으며 대화상자가 없을 때, 메시지 끝부분이 0.5초 동안 보이면 읽음으로 기록합니다. 긴 메시지는 마지막 80px이 보여야 하며, 짧은 메시지는 전체가 보여야 합니다. 고정 내비게이션·헤더에 가려진 끝부분도 기록하지 않습니다. 이는 화면에서 끝부분을 확인한 표시이며 내용 전체를 읽었다는 증명은 아닙니다. 화면 밖·숨겨진 창·이전 대화 열람 중 화면 아래의 새 메시지를 자동 확인하지 않고, 실제 화면에 보인 메시지만 기록합니다. 수정된 메시지는 수정본을 다시 확인해야 인원에 반영하며 삭제된 메시지는 읽음 표시를 숨깁니다. 같은 버전의 재시도는 읽음 인원·시각·갱신 이벤트를 중복 변경하지 않습니다. 실패 시 안내와 재시도를 제공하며, 화면·연결 복귀 때 보이는 대화를 다시 확인합니다. 읽음 갱신은 별도 채널과 인원 조회로 처리해 읽던 위치와 새 메시지 안내에 영향을 주지 않습니다. 탈퇴자의 기록은 제거하고 재가입 전 지연 요청은 거부합니다.

공동 도서관은 현재 그룹 멤버만 이용합니다. 공용 책상·의자·책장·조명·화분 5개를 기본 제공하며, 모든 멤버가 보라빛 액자와 실버 노트북을 골라 추가로 배치할 수 있습니다. 소품을 숨겼다가 다시 표시하면 마지막 위치·회전·크기·겹침 순서가 복원됩니다. 별도 코인 지출이나 보상은 없으며 개인 공부방과 배치는 독립적입니다. 마우스·터치·키보드·방향 버튼, 기본 위치 복원과 취소를 지원하고 다른 멤버의 저장과 충돌하면 초안을 유지합니다. 그룹장이 자신의 서재에서 선택한 책의 제목·저자·페이지 수·ISBN만 공동 목록에 복사합니다. 공동 도서는 최신순으로 20개씩 조회하며 같은 ISBN은 그룹에 한 번만 등록할 수 있습니다. 공동 도서의 정보 수정은 제공하지 않으며, 필요하면 제거 후 다시 등록합니다.
