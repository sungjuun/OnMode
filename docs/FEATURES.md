집중 기록은 1초 이상 저장합니다. 보상은 온전한 분 단위로 지급합니다. 사용자 지정 휴식이 0분이거나 설정 시간을 채우기 전에 종료하면 휴식은 시작하지 않습니다. 목표 연속 기록은 현재 설정한 목표를 기준으로 다시 계산합니다. 그룹 집계는 현재 브라우저의 시간대 기준입니다. 그룹 공동 목표는 월요일 시작 기준 주간 목표입니다.

ISBN 조회는 사용자가 검색 버튼을 누를 때 Open Library의 도서 메타데이터를 읽습니다. ISBN 10·13자리의 확인 숫자를 검증하고 ISBN-13으로 통일해, 한 서재에서 같은 ISBN을 중복 등록하지 않도록 합니다. 확인 숫자 검증만으로 실제 발급·출판 여부를 보증하지는 않습니다. 검색 결과는 제목·저자·페이지 수와 출처를 보여주며, 사용자가 적용한 뒤 직접 수정하고 저장합니다. 없는 저자·페이지 수는 추정하지 않고 필수 입력으로 남깁니다. 조회 실패·결과 없음·오프라인에서도 직접 등록할 수 있고 ISBN은 선택 사항입니다. 기존 직접 등록 자료는 유지하며, 다른 계정의 서재는 공개하지 않습니다. 제목·저자 검색은 작품과 판본을 구분해 각각 10개씩 조회합니다. 판본의 ISBN·페이지 수만 양식에 적용하며 저자는 작품 정보 기준으로 확인·수정할 수 있습니다. 작품별 중간 페이지 수나 다른 판본의 ISBN은 사용하지 않습니다. 선택한 판본의 페이지 수가 없으면 필수 직접 입력으로 남깁니다.

방 꾸미기는 아이템 배치·치우기와 위치 편집을 지원합니다. 책상·의자·조명·액자·화분·책장·노트북은 마우스·터치·키보드·방향 버튼으로 이동할 수 있으며, 벽지는 공간 테마로 적용합니다. 방과 벽·바닥 영역에 맞는 위치 범위 안에서 겹쳐 배치할 수 있습니다. 편집은 저장 전에 미리보기로 표시하고, 취소와 기본 위치 복원을 지원합니다. 개인 방과 공동 도서관에서 앞으로 가져오기·뒤로 보내기와 Page Up·Page Down으로 선택한 가구를 보이는 가구 사이에서 한 단계씩 이동할 수 있습니다. 위치와 순서는 함께 저장하고, 취소·기본 위치 복원·숨기기 후 재배치에도 일관되게 반영합니다. 회전·크기 편집은 후속 범위입니다. 브라우저 체험에서는 실제 그룹·온라인 인원·랭킹을 표시하지 않습니다.

챌린지는 그룹장이 생성하며 1~90일 동안 공동 집중 시간을 쌓습니다. 멤버는 별도 신청 없이 함께 참여하고, 시작 예정·진행 중·목표 달성·기간 종료·취소 상태를 확인합니다. 챌린지 생성과 시작 이후 시작한 집중이 종료일 안에 완료되어야 집계합니다. 취소 뒤에 종료한 집중은 제외합니다. 탈퇴한 멤버의 기존 기여는 공동 합계에 남지만, 계정 삭제 시 개인 기록과 함께 제거됩니다. 멤버별 표는 현재 가입 기간의 기여만 표시합니다. 챌린지에 별도 XP·코인 보상은 없으며 일반 집중 보상만 지급합니다.

공지는 그룹장이 작성·수정·삭제하며, 그룹 멤버만 읽을 수 있습니다. 제목 80자, 내용 5,000자 이내의 일반 텍스트를 지원합니다. 최신순으로 20개씩 더 불러올 수 있으며, 변경 내용은 기존 그룹 실시간 연결 또는 주기 조회로 갱신합니다. 수정·삭제는 읽었던 버전과 현재 버전이 같아야 합니다. 충돌 시 초안을 유지하고 최신 목록을 확인하도록 안내합니다. 새 그룹장이 기존 공유 공지를 이어서 관리합니다.

채팅은 현재 그룹 멤버만 조회·전송할 수 있으며, 가입 이전의 그룹 대화도 볼 수 있습니다. 일반 텍스트 2,000자 이내, 이전 대화 30개 단위 조회, 실시간 수신과 주기 조회, 실패 후 재전송을 지원합니다. 서버는 사용자별 분당 새 메시지 30개를 허용하며 같은 요청 ID의 재시도는 새 메시지로 세지 않습니다. 본인과 그룹장만 메시지를 삭제할 수 있고, 내용은 지우되 삭제 표시는 남깁니다. 계정 삭제 시에는 그 사용자의 메시지 행도 제거합니다. 첨부 파일·메시지 수정·읽음 표시는 후속 범위입니다.

공동 도서관은 현재 그룹 멤버만 이용합니다. 공용 책상·의자·책장·조명·화분 5개를 기본 제공하고 모든 멤버가 위치를 편집할 수 있습니다. 별도 코인 지출이나 보상은 없으며 개인 공부방과 배치는 독립적입니다. 마우스·터치·키보드·방향 버튼, 기본 위치 복원과 취소를 지원하고 다른 멤버의 저장과 충돌하면 초안을 유지합니다. 그룹장이 자신의 서재에서 선택한 책의 제목·저자·페이지 수·ISBN만 공동 목록에 복사합니다. 공동 도서는 최신순으로 20개씩 조회하며 같은 ISBN은 그룹에 한 번만 등록할 수 있습니다. 공동 도서의 정보 수정은 제공하지 않으며, 필요하면 제거 후 다시 등록합니다.

후속 독서 연결 기능으로 멤버는 공동 도서를 개인 서재로 가져와 집중 활동으로 선택할 수 있습니다. 기존 ISBN이 있으면 그 책과 원래 진도를 유지하며, 새로 가져온 책은 0쪽·일일 목표 10쪽으로 시작합니다. ISBN이 없는 책도 같은 공동 도서의 가져오기를 반복하면 중복되지 않습니다. 그룹장이 공유한 원본 도서는 자신의 기존 서재와 연결됩니다. 개인 진도·노트·기록은 공동 목록에 자동 공개하지 않습니다. 공동 목록에서 제거하거나 그룹이 삭제되어도 개인 서재로 가져온 책은 유지합니다. 그룹장 탈퇴·계정 삭제 후에는 남은 그룹의 도서·배치를 새 그룹장이 이어서 관리하고, 빈 그룹의 공동 자료는 삭제합니다.

바코드는 EAN-13 형식의 도서 ISBN을 카메라 또는 12MB 이하 JPG·PNG·WebP 사진에서 인식합니다. 인식 후에는 사용자가 ISBN 검색을 눌러 메타데이터를 조회하며 사진·영상은 전송하지 않습니다. 카메라는 명시적 시작과 브라우저 권한이 필요하고 스캔 성공·중지·창 닫기·검색 방식 변경·화면 숨김·장치 연결 종료 때 스트림을 정리합니다. 권한이 늦게 허용돼도 닫힌 화면의 스트림을 즉시 정지합니다. HTTPS·같은 기기의 로컬 주소에서 카메라를 사용할 수 있으며 실제 기기·브라우저별 인식률, 자동 초점, 네이티브 권한은 모바일 검증 범위입니다.
