웹 베타의 첫 작업으로 이메일 비밀번호 재설정을 구현했습니다. 실제 로컬 메일에서 링크를 받아 검증했으며, 요청하지 않은 브라우저와 재사용 링크는 차단되고 새 비밀번호로만 다시 로그인할 수 있습니다.

계정 삭제는 확인 문구, 현재 비밀번호, 서버의 최근 인증 검사를 거칩니다. 취소와 틀린 비밀번호, 오래된 인증 거부, 개인 기록·세션·그룹 기여분 삭제, 공유 그룹장 이관과 빈 그룹 제거, 삭제 전 JWT의 RPC 재사용 거부를 검증합니다. 체험 기록은 보존됩니다. 운영 계정은 삭제하지 않았습니다.

다크 모드는 MY 환경설정에서 선택합니다. 기기별 선택 저장, 화면 전환·새로고침 후 유지, 시스템 테마 변경 반영, 입력창·다이얼로그·차트·2D 공부방에 적용했습니다. 데스크톱 홈과 모바일 공부방 화면을 시각적으로 확인했습니다.

스터디 챌린지는 그룹장이 날짜·시간대와 공동 목표를 정해 생성하고, 종료 전에 취소할 수 있습니다. 서버에서 확인된 집중만 합산하며 별도 보상은 추가하지 않습니다. 멤버 화면의 실시간 갱신, 외부 사용자 조회와 일반 멤버 쓰기 차단, 요청 재시도·세션 완료 재시도의 중복 방지, 생성 이전·기간 밖·취소 이후 집중 제외, 그룹장 이관 후 관리 권한을 로컬 Supabase에서 검증했습니다. 모바일 다크 모드에서도 화면을 확인했습니다.

그룹 공지는 작성·수정·삭제, 최신순 페이지 조회, 멤버 화면의 실시간 갱신을 제공합니다. 일반 멤버 쓰기와 외부 조회 차단, 오래된 버전의 수정·삭제 거부, 동일 작성 시각의 페이지 경계와 재시도, 일반 텍스트 표시, 충돌 시 초안 보존을 검증했습니다. 그룹장 이관·계정 삭제 후 공유 공지가 유지되고 빈 그룹의 공지는 삭제되는 것도 확인했습니다. 모바일 다크 화면을 시각적으로 점검했습니다.

그룹 채팅은 멤버 간 메시지 전송과 실시간 수신, 이전 대화 조회, 본인·그룹장의 삭제를 제공합니다. 서버 저장 후 응답만 잃는 경우의 재전송, 발신자 위조 방지, 외부·탈퇴 멤버 접근 차단, 일반 텍스트 표시, 같은 시각의 페이지 경계, 읽던 위치 보존과 새 메시지 이동을 검증했습니다. 사용자별 전송 제한은 재시도를 중복 계산하지 않으며, 계정 삭제 시 본인 채팅을 제거하고 다른 멤버의 대화는 유지하는 것도 확인했습니다. 모바일 다크 화면과 한국어 연결 오류 안내를 점검했습니다.

공부방 배치는 마우스·터치 드래그, SVG 가구의 화살표·Shift+화살표 조작, 선택·방향 버튼으로 편집합니다. 저장·취소·기본 위치 복원, 방 밖 이동 제한, 재배치 후 위치 유지, 로컬·계정 저장과 새로고침 복원을 검증했습니다. 보유하지 않은 아이템이나 잘못된 좌표는 거부하고 구매·보상에는 영향을 주지 않는 것을 확인했습니다. 다른 곳에서 먼저 저장한 경우 초안을 유지하고 최신 배치를 다시 불러오도록 안내합니다. 이전 IndexedDB 기록은 초기화하지 않고 새 배치 필드를 더해 읽습니다. 모바일 Chromium의 터치 입력과 편집 화면을 확인했습니다.

ISBN 도서 조회는 Open Library의 제목·저자·페이지 수를 미리 보고 직접 수정해 서재에 등록합니다. ISBN 10·13자리 및 X 확인 숫자를 검사하고 13자리로 통일합니다. 조회 실패·누락 정보·결과 없음에 대한 직접 입력, 이전 검색 취소, 캐시와 요청 간격, 체험·계정 저장 후 복원, 동일 ISBN의 동시 중복 차단과 다른 사용자 서재 격리를 검증했습니다. CLI로 생성한 마이그레이션을 로컬에 적용했으며 기존 수동 도서·방 배치·서버 보상 회귀 테스트가 통과했습니다. 실제 브라우저에서 `9780140328721`을 조회해 제목·저자·96쪽 응답과 CORS를 확인했고, 데스크톱 밝은 화면 및 모바일 다크 화면을 시각적으로 점검했습니다. [조회 화면](assets/book-isbn.png)을 남겼습니다. 제목 검색·스캔은 후속 기능이며, 상용·대규모 출시 전 도서 제공자의 이용 정책에 맞는 운영 방식을 결정해야 합니다.

스터디 공동 도서관과 후속 개인 서재 연결을 구현했습니다. 멤버가 함께 편집하는 공용 가구 5종, 그룹장의 명시적 도서 공유·제거, 커서 페이지 조회와 실시간 갱신을 제공합니다. 공동 도서를 개인 서재로 가져오면 기존 ISBN과 원래 진도를 유지하거나 새 책을 0쪽부터 시작하며 집중 활동으로 연결합니다. 개인 노트와 진도는 자동 공개하지 않습니다. 저장 후 응답만 잃은 등록·가져오기 재시도, ISBN 없는 도서의 반복 가져오기, 서로 다른 사용자 간 권한·RLS, 배치 동시 저장과 충돌 시 초안 보존, 잘못된 좌표·공용 외 아이템 거부를 검증했습니다. 그룹장 탈퇴·계정 삭제 후 공동 자료와 새 그룹장의 관리 권한이 유지되고, 빈 그룹의 자료는 삭제되며 이미 가져온 개인 책은 보존됩니다. 개인 방·보상 회귀 검사와 Advisors도 통과했습니다. [모바일 다크 화면](assets/shared-library.png)을 확인했습니다. 공용 아이템 확장과 공유 독서 진도·목표는 후속 범위입니다.

개인 공부방과 공동 도서관의 앞뒤 겹침 순서 편집을 구현했습니다. 선택한 가구를 보이는 가구 사이에서 한 단계 앞으로·뒤로 옮기며, 버튼과 Page Up·Page Down을 지원합니다. 순서 변경 후 키보드 초점을 유지하고 SVG가 그려지는 순서와 실제 클릭 대상이 일치하는 것을 데스크톱·모바일에서 검증했습니다. 위치·순서의 원자적 저장, 새로고침·취소·기본값 복원, 숨긴 가구 재배치, 중복·잘못된 팔레트 거부, 이전 IndexedDB 및 순서 필드 없는 RPC 요청 호환을 확인했습니다. 공동 편집에서는 순서·위치 충돌이 하나의 버전으로 검출되며 초안과 멤버별 권한을 유지합니다. 개인 인벤토리·코인·보상은 유지하고, CLI 생성 마이그레이션의 로컬 적용과 DB·Advisors 검사도 통과했습니다. [모바일 다크 편집 화면](assets/room-layers.png)을 확인했습니다. 회전·크기 편집은 후속 범위입니다.

독서 편의 작업으로 제목·저자 검색과 카메라·사진 바코드 인식을 구현했습니다. 작품 검색 → 판본 목록 → 사용자 확인 → 기존 서재 저장으로 이어지며, 작품과 판본은 10개씩 페이지 이동합니다. 선택 판본의 ISBN·페이지 수를 사용하고 누락 정보는 필수 직접 입력으로 남깁니다. 검색어·방식 변경, 취소, 서비스 오류에서도 초안과 일일 목표를 유지합니다. 카메라는 명시적으로 시작하며 영상·사진은 로컬 EAN-13 디코더로 처리하고 사용자 확인 후 검색할 때 ISBN만 보냅니다. 생성한 실제 EAN-13 픽셀 이미지와 캔버스 영상 스트림을 디코딩해 데스크톱·모바일 Chromium에서 검증했습니다. 성공·중지·창 닫기·방식 변경·배경 전환·장치 종료 및 늦게 허용된 권한의 트랙 정리도 확인했습니다. 물리 카메라와 모바일 실기기·네이티브 권한 검증은 남아 있습니다. 실제 Open Library 제목 검색·판본 조회의 CORS와 양식 적용을 새 브라우저에서 확인했으며, 계정 저장·새로고침·ISBN 중복 방지와 기존 DB/REST 검사가 통과했습니다. 스키마 변경은 없고 디코더는 별도 청크·고정 버전으로 추가했습니다. npm audit에서 설치 의존성 취약점 보고는 0건입니다.
