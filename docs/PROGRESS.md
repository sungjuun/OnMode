# 진행 현황 · 2026-11-04

웹 MVP를 구현했습니다. 로컬 체험 모드에서 자격증·과목과 도서 등록 → 독서 진도 저장 → 타이머 일시정지·복원·완료 → XP와 코인 → 조명 구매·배치 → 홈·MY 기록 조회를 확인했습니다. Supabase 계정과 스터디 기능은 ONMODE 전용 로컬 Docker 스택으로 검증했습니다.

웹 베타의 첫 작업으로 이메일 비밀번호 재설정을 구현했습니다. 실제 로컬 메일에서 링크를 받아 검증했으며, 요청하지 않은 브라우저와 재사용 링크는 차단되고 새 비밀번호로만 다시 로그인할 수 있습니다.

계정 삭제는 확인 문구, 현재 비밀번호, 서버의 최근 인증 검사를 거칩니다. 취소와 틀린 비밀번호, 오래된 인증 거부, 개인 기록·세션·그룹 기여분 삭제, 공유 그룹장 이관과 빈 그룹 제거, 삭제 전 JWT의 RPC 재사용 거부를 검증합니다. 체험 기록은 보존됩니다. 운영 계정은 삭제하지 않았습니다.

다크 모드는 MY 환경설정에서 선택합니다. 기기별 선택 저장, 화면 전환·새로고침 후 유지, 시스템 테마 변경 반영, 입력창·다이얼로그·차트·2D 공부방에 적용했습니다. 데스크톱 홈과 모바일 공부방 화면을 시각적으로 확인했습니다.

스터디 챌린지는 그룹장이 날짜·시간대와 공동 목표를 정해 생성하고, 종료 전에 취소할 수 있습니다. 서버에서 확인된 집중만 합산하며 별도 보상은 추가하지 않습니다. 멤버 화면의 실시간 갱신, 외부 사용자 조회와 일반 멤버 쓰기 차단, 요청 재시도·세션 완료 재시도의 중복 방지, 생성 이전·기간 밖·취소 이후 집중 제외, 그룹장 이관 후 관리 권한을 로컬 Supabase에서 검증했습니다. 모바일 다크 모드에서도 화면을 확인했습니다.

그룹 공지는 작성·수정·삭제, 최신순 페이지 조회, 멤버 화면의 실시간 갱신을 제공합니다. 일반 멤버 쓰기와 외부 조회 차단, 오래된 버전의 수정·삭제 거부, 동일 작성 시각의 페이지 경계와 재시도, 일반 텍스트 표시, 충돌 시 초안 보존을 검증했습니다. 그룹장 이관·계정 삭제 후 공유 공지가 유지되고 빈 그룹의 공지는 삭제되는 것도 확인했습니다. 모바일 다크 화면을 시각적으로 점검했습니다.

운영 Supabase 또는 Vercel은 연결하지 않았습니다. 운영 SMTP와 이메일 확인, 로그·백업 정책, Android/iOS 네이티브 프로젝트 및 실기기 검증은 후속 작업입니다. 자세한 범위는 [로드맵](ROADMAP.md)을 참고하세요.
