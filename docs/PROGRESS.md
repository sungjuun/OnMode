# 진행 현황 · 2026-11-04

웹 MVP를 구현했습니다. 로컬 체험 모드에서 자격증·과목과 도서 등록 → 독서 진도 저장 → 타이머 일시정지·복원·완료 → XP와 코인 → 조명 구매·배치 → 홈·MY 기록 조회를 확인했습니다. Supabase 계정과 스터디 기능은 ONMODE 전용 로컬 Docker 스택으로 검증했습니다.

| 검증 | 결과 |
| --- | --- |
| ESLint, TypeScript strict, Vite 프로덕션 빌드 | 통과 |
| Vitest | 4개 통과: 타이머 복원·상한, 일시정지, 긴 휴식, IndexedDB 동시 시작·보상·구매 |
| Playwright 체험 모드 | 4개 통과: 데스크톱·모바일에서 개인 흐름과 4가지 타이머 표시·자동 완료 |
| Playwright 연결 모드 | 2개 통과: 비공개 그룹 초대·실시간 집중 상태, Mailpit으로 받은 비밀번호 재설정 링크의 교환과 재로그인 |
| Supabase DB/REST | 마이그레이션 재적용, 가입·로그인, 타 사용자 기록 접근 차단, 그룹장 권한, 공개 가입과 비공개 초대, 순위와 그룹 누적, Realtime, 시간 위조·중복 보상·중복 구매 방지 확인 |
| Supabase Advisors | 경고 이상 이슈 없음 |
| 반응형과 화면 점검 | 320·768·1024·1440px에서 7개 경로의 가로 넘침 없음. 홈 데스크톱·모바일과 2D 공부방 이미지 확인 |
| npm audit / Capacitor Doctor | 설치 의존성 취약점 보고 0건. Capacitor CLI·core 확인 |

웹 베타의 첫 작업으로 이메일 비밀번호 재설정을 구현했습니다. 실제 로컬 메일에서 링크를 받아 검증했으며, 요청하지 않은 브라우저와 재사용 링크는 차단되고 새 비밀번호로만 다시 로그인할 수 있습니다.

운영 Supabase 또는 Vercel은 연결하지 않았습니다. 운영 SMTP와 이메일 확인, 계정 삭제 절차, Android/iOS 네이티브 프로젝트 및 실기기 검증은 후속 작업입니다. 자세한 범위는 [로드맵](ROADMAP.md)을 참고하세요.
